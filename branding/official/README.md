# Sources graphiques officielles

Ces deux fichiers proviennent des URL fournies par le responsable du projet. Ils sont conservés octet pour octet, sans recréation, recoloration, suppression de fond ou réencodage. [sources.json](sources.json) contient les réponses HTTPS et les empreintes SHA-256.

- `Logo-512-1.png` : 512 × 512, lettres bleues sur disque blanc, utilisé pour Android et l'icône Fastlane/F-Droid.
- `logo-fond-clair_lwsoptimized.webp` : 664 × 545, variante à lettres bleues et fond transparent, conservée comme original officiel supplémentaire.

La variante transparente à lettres claires déjà présente dans le projet est conservée sans modification dans `app/src/main/res/drawable-nodpi/le_fil_logo_dark.png`. Les règles d'intégration figurent dans [BRANDING.md](../../docs/BRANDING.md).
